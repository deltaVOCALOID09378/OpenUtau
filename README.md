# OpenUtau (DELTA SYNTH Edition) 🇹🇭

**OpenUtau** คือโปรแกรมแก้ไขเสียงร้อง (Editor) แบบโอเพนซอร์สที่ถูกนำมาพัฒนาต่อยอดและยกระดับโดย **DELTA SYNTH** เพื่อมอบประสบการณ์ที่ดีที่สุดให้กับผู้ใช้งานในชุมชนเสียงสังเคราะห์ โดยเฉพาะการปรับแต่งให้เข้ากับการใช้งานของคนไทยอย่างสมบูรณ์แบบ ทั้งในด้านความเสถียรและฟีเจอร์อัจฉริยะที่ตอบโจทย์ทุกจินตนาการทางดนตรี

## 🚀 การอัปเกรดพิเศษโดย DELTA SYNTH (Exclusive Enhancements)

โปรเจกต์นี้ผ่านการปรับแต่งโครงสร้างโค้ดแบบ **Zero-Defect Refactoring** เพื่อให้ทำงานได้อย่างเสถียร ไร้ข้อผิดพลาด และพร้อมรองรับฟีเจอร์ใหม่ๆ โดยมีจุดเด่นที่เราภูมิใจนำเสนอดังนี้:

*   **Bilingual UI (อินเทอร์เฟซสองภาษา):** รองรับการแสดงผลทั้งภาษาไทยและภาษาอังกฤษอย่างสมบูรณ์แบบในตัวเดียว ใช้งานง่าย เข้าถึงได้ทุกคนโดยไม่ต้องเปลี่ยน System Locale
*   **Thai Phonemizer แบบจัดเต็ม:** รองรับระบบการร้องภาษาไทยหลากหลายรูปแบบ ไม่ว่าจะเป็น **Thai VCCV-CVVC** (คิดค้นต้นฉบับโดย Ferina and Printmov), **Thai Arpasing**, และรองรับการทำงานร่วมกับ **Thai Diffsinger AI** อย่างเต็มรูปแบบ
*   **Automated Vocal Tuning:** ฟีเจอร์จูนเสียงอัตโนมัติที่ช่วยยกระดับความสมจริง:
    *   **Consonant Expansion:** ช่วยยืดระยะเวลาของเสียงพยัญชนะให้การออกเสียงมีความชัดเจน ไพเราะ และเป็นธรรมชาติมากขึ้น
    *   **Automated Pitch & Vibrato:** สร้างเส้นกราฟเสียง (Pitch Curves) และใส่ลูกคอ (Vibrato) ให้อัตโนมัติในระหว่างกระบวนการแมปฟอนีม

## 🛠️ คุณสมบัติหลักที่โดดเด่น (Main Features)

*   **ประสบการณ์การใช้งานที่ทันสมัย:** อินเทอร์เฟซลื่นไหล รองรับการซูมและเลื่อนไทม์ไลน์ด้วยเมาส์อย่างเป็นธรรมชาติ
*   **เครื่องมือปรับแต่งเสียงระดับมืออาชีพ:** นำเข้าไฟล์ MIDI และ VSQX (Vocaloid 4) ได้ทันที พร้อม Vibrato Editor และระบบ Expressions ที่ให้ความละเอียดสูง
*   **Pre-rendering อัจฉริยะ:** ระบบประมวลผลเสียงล่วงหน้า ช่วยให้คุณฟังพรีวิวระหว่างการปรับจูนได้ทันทีโดยไม่ต้องรอ Render 
*   **รองรับเทคโนโลยี AI:** พร้อมใช้งานร่วมกับนักร้องระบบ ENUNU (NNSVS), DiffSinger และโมเดลเสียงแห่งอนาคต
